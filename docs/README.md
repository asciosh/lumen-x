# docs

Images used by the main README and the static demo.

- `banner.png`, `demo.png`: README header and a screenshot of the demo page
- `api-docs.png`, `forecast_real.png`, `forecast.png`, `forecast_global.png`, `feature_importance.png`, `wape_by_family.png`: figures from the notebooks and the forecasting service
- `demo/`: the static demo published with GitHub Pages (<https://asciosh.github.io/lumen-x/demo/>). It reads four JSON files that are a saved snapshot of a real run, so it cannot compute anything new. It uses the same `app.css` and fonts as the dashboard: if the dashboard look changes, copy `app.css` and `fonts/` there again.
